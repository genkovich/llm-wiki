# Plan Mode

A Claude Code mode where the agent first lays out a plan of actions and waits for approval before executing. Activated explicitly (shift+tab cycle) or via ExitPlanMode.

## Purpose

- Control before irreversible actions
- Architectural alignment before code
- Less rework on complex tasks

## Open questions

- When plan mode helps vs. gets in the way (short tasks)
- How to combine with the brainstorming skill
