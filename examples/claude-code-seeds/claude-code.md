# Claude Code

Anthropic's official CLI for agentic programming. Available in the terminal, the desktop app (Mac/Windows), the web (claude.ai/code), and IDE extensions (VS Code, JetBrains).

## Key subsystems

- [[entities/skills]] — behavior modules triggered by description
- [[entities/subagents]] — specialized agents that execute delegated tasks
- [[entities/plan-mode]] — planning mode before execution
- Hooks — event-driven hooks (PreToolUse, PostToolUse, etc.)
- MCP — integrating external tools/resources via the Model Context Protocol
